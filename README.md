# Hartzell AI Stack

> How a 63-year-old HVAC contractor in Kingfisher, Oklahoma runs a $1M+ business with Claude Code.

I'm Dave Hartzell. Master HVAC, 45 years on the tools, 15+ years owner of [Hartzell's Heat & Air](https://hartzellsheatair.com). 4.8 stars, 289 reviews, 5-person crew.

This repo is the public, sanitized blueprint of the AI stack that runs every part of my business: marketing, dispatch, accounting, content, voice agents, KPI dashboards, HVAC-specific automation. I built it on top of work from a handful of generous Claude skill authors. I'm publishing it so other contractors can see what's possible, and so the people whose work I built on get the credit.

## What's actually inside

| Layer | What it does |
|-------|--------------|
| **Marketing** | Google + Meta ad audits, copywriting, landing pages, social, blog content, SEO + GEO, podcast production |
| **Operations** | HCP automation, dispatch, tech feedback, KPI dashboard, daily/weekly reports |
| **Sales** | DaveAI overflow phone agent, AI booking that writes straight into Housecall Pro, lead intake, estimate follow-up |
| **Finance** | 6-agent accounting pipeline (data prep, categorize, reconcile, report, insights, tax prep) |
| **Content** | Blog, podcast (3 shows), shorts, YouTube, Facebook, all in one voice |
| **HVAC-specific** | Pricing engine, Trane and Mitsubishi quote system, JBW warranty, R-454B conversion logic, utility rebates |
